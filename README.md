# Amazon ABA 单文件网页分析器

版本：1.1.1

打开 `index.html`，在浏览器中选择一份 Amazon Brand Analytics「搜索分析 - 热门搜索词 - 简单报告」CSV。

- 一次只导入一份 CSV；无需安装、无需翻译，报告数据不会上传。
- 最终表格显示：排名、搜索词、TOP3点击、TOP3转化。
- 点击搜索词会在新标签页打开对应站点的 Amazon 搜索结果。
- 点击搜索词左侧的 Google Trends 图标，会按当前站点地域打开该词的趋势页面。
- 文件名前缀会自动识别 US、CA、MX、GB、DE、FR、IT、ES、JP、AU；也可在页面中手动切换站点。
- 页面没有分页。数据区采用虚拟滚动，几十万条结果中仅渲染当前可见行。
- 支持关键词、排名区间及 TOP3 点击/转化阈值筛选。

TOP3 点击/转化分别为报告前三名商品相应份额字段之和；空值按 0 计算。刷新或关闭网页后，需重新选择 CSV。
