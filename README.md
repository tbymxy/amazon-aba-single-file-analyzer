# Amazon ABA 单文件网页分析器

版本：1.3.1

打开 `index.html`，在浏览器中选择一份 Amazon Brand Analytics「搜索分析 - 热门搜索词 - 简单报告」CSV。

- 可导入一份 CSV 浏览，也可同时选择两份相同站点的周报进行对比；无需安装、无需翻译，报告数据不会上传。
- 周数和日期只从 CSV 第一行自动识别，并清洗为 `周 N | YYYY-MM-DD - YYYY-MM-DD`。
- 单份模式显示：排名、搜索词、TOP3点击、TOP3转化。
- 对比模式以较新周数据为主，增加新周排名、旧周排名和涨跌幅度；旧周不存在的搜索词，其旧排名记为 0。
- 涨跌幅度按“旧排名 − 新排名”计算，正数表示排名提升，负数表示排名下降。
- 点击搜索词会在新标签页打开对应站点的 Amazon 搜索结果。
- 点击搜索词左侧的 Google Trends 图标，会按当前站点地域打开该词的趋势页面。
- 文件名前缀会自动识别 US、CA、MX、GB、DE、FR、IT、ES、JP、AU；也可在页面中手动切换站点。
- 采用双栏分页：每页 100 个物理行，左、右各显示 100 条连续结果，即每页最多 200 条。
- 页码区显示首尾页和以当前页为中心的 21 个连续页码，并支持输入页码直接跳转。
- 开始筛选时记住当前页；全部筛选条件清空后自动返回筛选前页码。
- 支持关键词、排名区间及 TOP3 点击/转化阈值筛选。
- 对比模式支持涨跌幅度区间筛选；点击新排名、旧排名或涨跌幅度表头，可按升序、降序、取消的顺序循环，并可叠加多列排序。
- “重置”可一键清空全部筛选条件并恢复筛选前页码；排序状态保持不变。

TOP3 点击/转化分别为报告前三名商品相应份额字段之和；空值按 0 计算。刷新或关闭网页后，需重新选择 CSV。
