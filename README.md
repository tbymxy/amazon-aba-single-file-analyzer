# Amazon ABA 热门搜索词分析器 PWA

版本：1.6.0
在线地址：https://tbymxy.github.io/amazon-aba-single-file-analyzer/

## 使用

1. 使用最新版 Chrome 或 Edge 打开在线地址。
2. 选择统一的“导入”入口，可一次选择一份或多份、多站点、多周次 CSV，也可以日后继续追加。
3. 网页会把分析所需的四个字段压缩保存在当前浏览器的本地存储中；刷新或重新打开无需再导入。
4. 通过“站点 / 起始周 / 结束周 / 查看周 / 对比周”切换数据。默认打开结束日最新的报告。
5. 可通过浏览器的“安装应用”将它安装为独立 PWA 窗口；页面外壳可离线打开。

## 数据与功能

- 支持 US、CA、MX、GB、DE、FR、IT、ES、JP、AU。
- “导入”同时覆盖单份、两份对比和批量导入；恰好选择两份同站点报告时自动进入对比。
- 从文件名前缀识别站点；无前缀时会要求输入站点，不根据搜索词语言猜测。
- 周数与日期只从 CSV 第一行识别，标准化为 `周 N | YYYY-MM-DD - YYYY-MM-DD`。
- `TOP3点击` 和 `TOP3转化` 分别为前三名商品的点击份额、转化贡献占比之和；空值按 0 计算。
- 两周对比以“旧排名 − 新排名”计算涨跌；旧周不存在的词记为 0。
- 保留关键词、排名、TOP3 上限、涨跌区间筛选，多列三态叠加排序，以及双栏分页。
- 每页 100 个物理行，左右各 100 条，最多显示 200 条，不一次渲染整份报告。
- 每个搜索词的“排名趋势”使用当前站点和起止周范围，按时间从旧到新显示 ABA 排名。
- 排名数字越小折点越高；缺失搜索词的周次留空并断开折线，不当作排名 0。
- 悬停折点显示周次、日期和准确排名；点击小图可打开详细趋势图，当前查看周使用蓝色强调。
- 趋势仅查询当前页最多 200 个词，并在 Worker 中读取二进制排名索引，不扫描全年全部搜索词。
- 点击搜索词打开对应站点 Amazon 搜索；左侧图标打开对应地区 Google Trends。
- 完全相同的文件按站点、周结束日和 SHA-256 跳过；同站点同周的不同版本会询问是否替换。

## 本地持久化说明

- CSV 不会上传到 GitHub 或其他服务器，原始 CSV 也不会复制到网站。
- IndexedDB 保存报告目录，OPFS 保存 gzip 压缩的分析数据和趋势二进制索引。
- 1.4.0 已导入的报告不需要重新选择 CSV；首次显示趋势时会在后台逐份建立索引，页面会显示进度。
- 数据与“网站域名 + 当前浏览器配置文件”绑定，不会跨电脑或跨浏览器自动同步。
- 无痕模式、清除该站点数据、删除浏览器配置文件，都会导致已导入数据丢失。
- 网页会申请持久存储；是否批准由浏览器决定。安装 PWA、保持站点活跃并避免手动清理站点数据，可降低被浏览器回收的风险。
- 建议保留原始 CSV 作为备份。
- “本地数据”可查看已导入报告对应的 OPFS 文件名和大小；由于浏览器安全限制，网页不能直接打开内部目录，可使用“导出到文件夹”复制到普通 Windows 文件夹查看和备份。

直接通过 `file://` 打开本地 HTML 时，部分浏览器不提供 OPFS/PWA 能力；建议使用上述 HTTPS 在线地址。
